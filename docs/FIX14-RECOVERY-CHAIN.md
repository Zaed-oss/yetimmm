# fix14 — خطة التحقق (EA 2.46، غير مُترجم هنا)

1. **ترجمة:** MetaEditor ← F7 بلا أخطاء.
2. **Strategy Tester (Hedging):** شغّل حتى تحدث سلسلة SELL يخسر ثم BUY، وSELL يخسر ثم SELL، وBUY يخسر ثم BUY، وBUY يخسر ثم SELL.
3. **اقرأ سجل Experts / Orders.csv** وابحث عن:
   - `RECOVERY_TRACE [REVERSE_PREARM]` قبل الـ SL: يجب أن يظهر `required risk` أكبر من السابق و`final lot` ≥ لوت الصفقة المفتوحة.
   - `REVERSE_FILLED`: اللوت المنفَّذ = لوت الأمر المسبق.
   - `LEDGER: SL net ... CYCLE NET a -> b` بعد الإغلاق: الصافي نزل بقدر الخسارة (تسجيل **مرة واحدة**).
   - إن لم يكبر اللوت: `RECOVERY_LOT_NOT_GROWN` ويذكر السبب. هذا سلوك مقصود عندما تمنع حدود الأمان الزيادة (Max Lot / Round-Up Max Over % / CLAMP_MIN) — لا يُرفع لوت خارج الحدود.
   - `LEDGER WAIT` / `LEDGER_STALE_RELEASE`: تعني أن صفقة مغلقة لم تُحجز؛ أرفق السجل.
4. **أعد تشغيل MT5 بعد خسارة** وتأكد أن الدفتر يُستعاد ولا تُسجَّل الخسارة مرتين.
5. **حساب تجريبي** قبل أي حساب حقيقي.
