# Yetimmm v4.6

نظام تداول XAUUSD على MT5 يتكوّن من ثلاثة أجزاء تعمل معاً:

| الجزء | المجلد | وظيفته |
|---|---|---|
| **EA** | `ea/Yetimmm.mq5` | يعمل داخل MT5: ينفّذ الأوامر المعلقة وتسلسل المخاطرة، ويرسل الحالة والتقويم الاقتصادي للخادم |
| **Worker** | `worker/` | جسر Cloudflare: تسجيل الدخول، الجلسات، الأوامر، التنبيهات والإشعارات |
| **التطبيق** | `index.html` + `anim/` + `news/` | واجهة تلجرام Mini App (تُرفع على GitHub Pages) |

```
yetimmm/
├── index.html            التطبيق (يُرفع مع anim/ و news/ كما هي)
├── anim/                 طبقة الأنيميشن
├── news/                 تبويب الأخبار والإشعارات
├── worker/
│   ├── worker.js         نقطة الدخول + Hub (حساب MT5 الواحد)
│   ├── news.js           Notify (التقويم + الإشعارات)
│   ├── wrangler.toml
│   └── .dev.vars.example
├── ea/Yetimmm.mq5
├── tests/                اختبارات الـ Worker (28 اختباراً بينها دورة الأوردرات الكاملة)
├── scripts/check.mjs     فحص سريع للحزمة كلها
├── CHANGELOG.md
└── package.json
```

## التشغيل خطوة بخطوة

### 1) الـ Worker (Cloudflare)
```bash
npm install
cd worker
npx wrangler login
npx wrangler secret put BOT_TOKEN       # توكن بوت تلجرام من @BotFather
npx wrangler secret put APP_PASSWORD    # كلمة سر التطبيق (إلزامية)
npx wrangler secret put PAIR_CODE       # رمز ربط الـ EA بالحساب (موصى به؛ بدونه يُستخدم APP_PASSWORD)
cd ..
npm run deploy
```
> **مهم:** لا توجد كلمة سر افتراضية. إن لم تضبط `APP_PASSWORD` يرفض الخادم تسجيل الدخول برسالة واضحة.

بعد النشر يظهر رابط مثل `https://yetimmm-bridge.<حسابك>.workers.dev`. افتحه في المتصفح: يجب أن ترى `{"ok":true,"service":"yetimmm-bridge"...}`.

### 2) الـ EA (MT5)
1. انسخ `ea/Yetimmm.mq5` إلى `MQL5/Experts/` ثم افتحه في MetaEditor واضغط **F7** للترجمة.
2. في MT5: **Tools ▸ Options ▸ Expert Advisors** فعّل *Allow WebRequest for listed URL* وأضف رابط الـ Worker (MT5 لا يسمح للـ EA بإضافته بنفسه).
3. اسحب الـ EA على شارت **XAUUSD** وتأكد أن زر **AutoTrading** مفعّل.
4. في مدخلات الـ EA: `InpBrUrl` = رابط الـ Worker، و**`InpBrPairCode` = نفس قيمة `PAIR_CODE`** (مرة واحدة لكل حساب). عند قبول الرمز يُصدر الـ Worker سراً خاصاً للـ EA ويحفظه الـ EA تلقائياً، ثم لا يُرسل الرمز بعد ذلك. بعدها (اختياري) توكن البوت وأرقام المصرّح لهم.
> **بدون رمز الربط يُرفض أي حساب جديد** (`403 pair_required`) فلا يستطيع EA غريب أن يسبق EA الحقيقي ويحجز الحساب. حسابات v4.5 المربوطة سابقاً تستمر بالعمل، وتُرقّى للنظام الجديد عند أول مرة تُدخل فيها الرمز. إن أعدت تثبيت الـ EA وضاع ملف إعداداته فأدخل الرمز ليُعاد الربط (يُلغى السر القديم تلقائياً).

### 3) التطبيق (GitHub Pages)
1. في `index.html` عدّل `CONFIG.api.baseUrl` إلى رابط الـ Worker الخاص بك.
2. ارفع `index.html` و`anim/` و`news/` إلى مستودع GitHub وفعّل Pages.
3. في @BotFather: `/setmenubutton` ثم ضع رابط Pages، فيُفتح التطبيق من داخل البوت.
4. (**مطلوب للإنتاج**؛ `npm run check` يفشل بدونه) بعد معرفة رابط Pages تأكد أن في `wrangler.toml` المتغير `ALLOWED_ORIGIN` ليقبل الـ Worker طلبات تطبيقك فقط، ثم `npm run deploy`.

## الإعدادات (كلها تُغيَّر بلا تعديل كود)
| الاسم | الافتراضي | الوصف |
|---|---|---|
| `BOT_TOKEN` *(secret)* | — | توكن البوت. بدونه لا يعمل الدخول من تلجرام |
| `APP_PASSWORD` *(secret)* | — | كلمة السر. **تغييرها يُنهي كل الجلسات القديمة تلقائياً** |
| `SESSION_EPOCH` | 1 | ارفعه (1 ← 2) لإخراج الجميع فوراً |
| `LOCK_SECONDS` / `MAX_ATTEMPTS` | 120 / 8 | القفل بعد محاولات خاطئة (لكل مستخدم تلجرام/IP) |
| `SESSION_DAYS` | 30 | عمر الجلسة المنزلق |
| `REQUIRE_TG` | 1 | `0` = السماح بالدخول من متصفح عادي (للتجربة فقط) |
| `PAIR_CODE` *(secret)* | = `APP_PASSWORD` | رمز ربط الـ EA بالحساب (`InpBrPairCode` في الـ EA) |
| `PAIR_MAX_FAILS` / `PAIR_LOCK_SEC` | 10 / 300 | قفل الربط بعد محاولات رمز خاطئة (لا يؤثر على EA مربوط) |
| `EA_STALE_SEC` | 20 | ثوانٍ بلا مزامنة قبل اعتبار الـ EA غير متصل. **مصدر واحد**: التطبيق يقرأها من السيرفر (`eaStaleSec`) |
| `NEWS_SCOPE` | `server` | `server` = تقويم وإشعارات منفصلة لكل سيرفر وسيط · `global` = مشاركة واحدة (سلوك v4.5) |
| `SESSION_TOUCH_SEC` | 600 | أي طلب موثّق يمدّد الجلسة (الكتابة للتخزين مرة كل هذه الثواني فقط) |
| `ALLOWED_ORIGIN` | فارغ (مغلق) — مضبوط في `wrangler.toml` | أصل/أصول تطبيق الويب المسموحة (CORS)، النطاق فقط بلا مسار، يفصلها فاصلة. `*` للتجربة المحلية فقط |
| `MT5_FEED` | 1 | `0` = تجاهل تقويم MT5 واستخدام ForexFactory/TE فقط |
| `TE_KEY` *(secret)* | — | اختياري: Trading Economics كاحتياطي |

## حل المشاكل
| العرض | السبب والحل |
|---|---|
| "الخادم غير مهيّأ" | لم تضبط `APP_PASSWORD`: `wrangler secret put APP_PASSWORD` |
| "افتح التطبيق من داخل بوت تلجرام" | الدخول مقصور على تلجرام؛ افتحه من زر البوت (أو `REQUIRE_TG=0` للتجربة) |
| "البوت غير شغّال على هذا الحساب" | الـ EA غير متصل: تأكد من AutoTrading ورابط WebRequest والشارت XAUUSD |
| الـ EA لا يتصل | الرابط غير مضاف في *Allowed URLs* في خيارات MT5 |
| سجل الـ EA: `NOT PAIRED yet` (HTTP 403) | الحساب جديد ولم تدخل رمز الربط: ضع `InpBrPairCode` = قيمة `PAIR_CODE` (أو `APP_PASSWORD` إن لم تضبطه) |
| سجل الـ EA: `pairing code REJECTED` | الرمز في الـ EA لا يطابق الـ Worker |
| سجل الـ EA: `bound to another EA install` | ضاع ملف إعدادات الـ EA أو ثُبّت EA آخر: أدخل رمز الربط ليُعاد الربط |
| بطاقة «التداول معطّل في MT5» | زر AutoTrading مطفي، أو الحساب/الرمز لا يسمح بالتداول الآن (تعرض البطاقة السبب بالضبط) |
| "محاولات كثيرة" | قفل دقيقتين؛ إدخال كلمة سر صحيحة والبوت مطفي **لا** يُحسب محاولة خاطئة |
| لا تصلك إشعارات تلجرام | سجّل الدخول مرة من داخل تلجرام ليُسجَّل حسابك على الحساب |

## قرارات تداول يجب أن تعرفها
- **`InpBreachPolicy` الافتراضي = `BREACH_WAIT`** (الفلسفة حرفياً): بعد ضرب SL يوضع الأمر المعاكس (Stop) عند مستوى الوقف وينتظر السعر. `BREACH_MARKET` خيار متقدم اختياري (عكس فوري بسعر السوق إن كان السعر قد تجاوز المستوى). إن كانت إعدادات شارتك القديمة محفوظة بـ MARKET فغيّرها يدوياً؛ يطبع الـ EA السياسة الفعلية في سجل البدء.
- **`InpProtectCloseSec = 20`**: صفقة بلا SL/TP لم تُحمَ خلال 20 ثانية تُغلق إغلاقاً طارئاً. هذا قرار تداول: مشكلة اتصال مؤقتة قد تغلق صفقة بخسارة أكبر من المخاطرة المخططة. `0` = لا إغلاق قسري (تنبيه + إعادة محاولة فقط) لكن قد تبقى صفقة بلا حماية.
- **نسبة 1:20** قيمة قوية: إن كانت المسافة 1$ (4138/4137) فهدف الشراء ≈ 4158 والبيع ≈ 4117. تظهر الواجهة تحذيراً صريحاً بالأسعار عند نسبة ≥ 10.
- **هدف الربح بعد التعويض** ليس TP ثابتاً: المخاطرة التالية = (الخسارة المتراكمة + الهدف) ÷ النسبة.
- **منطقة الوضع (`InpZoneGate`)**: إن كان السعر خارج المنطقة تحفظ المستويات لكن لا يظهر أمر في MT5؛ تعرض الواجهة بطاقة «بانتظار السعر» بالمستويين والسبب.

## ما الذي تثبته الفحوصات وما لا تثبته
`npm run check` و`npm test` تثبتان سلامة **البنية والـ Worker** ومنع رجوع أخطاء التدقيق. **لا** تثبتان أن الـ EA يُترجم (اضغط F7 في MetaEditor) ولا أن الاستراتيجية صحيحة تداولياً (Strategy Tester ثم حساب تجريبي: Hedging وNetting، تنفيذ سريع، فجوات سعرية، صفقة يدوية، إغلاق خارجي). عبارة «All checks passed» ليست حكماً على الاستراتيجية.

## حدود معروفة (للعلم)
- **لم يُترجم الـ EA في بيئة العمل** (لا يوجد MetaEditor). عُدّل بحذر (بدون أي تعديل في منطق التداول) وفُحصت بنيته؛ إن ظهر خطأ ترجمة فاضغط F7 وأرسل نصه.
- ربط الحساب يتم برمز ثابت تضعه أنت (`PAIR_CODE` ↔ `InpBrPairCode`) وليس بمولّد رمز من داخل التطبيق: التطبيق نفسه يحتاج EA متصلاً ليسمح بتسجيل الدخول، فلا يمكن توليد رمز منه قبل أول ربط.
- تلجرام ما زال داخل الـ EA لإرسال الإشعارات فقط: في وضع الجسر المشترك يتوقف `getUpdates` تماماً (الأوامر تأتي من التطبيق). نقل الإشعارات كلياً إلى الـ Worker وحذف التوكن من الـ EA خطوة معمارية لاحقة (تحتاج قناة أحداث من الـ EA).
- الأخبار والإشعارات تُفصل الآن لكل سيرفر وسيط (`NEWS_SCOPE=server`)؛ تنبيهات v4.5 المحفوظة في الشريحة المشتركة القديمة لا تظهر في الشرائح الجديدة (أعد تفعيلها أو استخدم `NEWS_SCOPE=global`).
